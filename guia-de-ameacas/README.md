# Guia de Ameaças

> _"O mundo não acabou com um estrondo. Ele acabou com um grito, e depois silêncio."_

Em **EXTINÇÃO**, os inimigos não são apenas sacos de Pontos de Vida. Eles são quebra-cabeças táticos. Cada ameaça exige uma resposta diferente: você corre da Horda, se esconde do Volátil e flanqueia o Mercenário.

### 🧬 A Origem (Lore)

O "Vírus Z" é um agente biológico mutável. Ele não apenas reanima os mortos; ele reescreve a biologia do hospedeiro para matar. O vírus se adapta, criando desde os lerdos "Necróticos" até predadores alfa projetados para caçar.

Mas lembre-se: o vírus não é o único perigo. A fome, o desespero e a ganância transformaram os humanos não-infectados em monstros igualmente letais.

***

### 🛠️ Oficina: Criando Suas Ameaças

Se você quiser criar um monstro novo (um "Cão-Zumbi", um "Urso Mutante" ou um "Drone de Combate"), use estas diretrizes para balancear os números.

#### 1. Defina a Classe de Ameaça

* **Classe 1 (Carne de Canhão):** Zumbis comuns, cães, civis armados. Perigosos apenas em grupo.
* **Classe 2 (Caçador):** Rápidos e letais. Stalkers ou Soldados Treinados. Exigem 2 Sucessos para acertar.
* **Classe 3 (Tanque):** Monstros gigantes ou Blindados. Exigem armas pesadas ou táticas de demolição.
* **Classe 4 (Ápice/Boss):** O predador final. Geralmente tem regras especiais (regeneração, imunidades).

#### 2. Os Atributos do Inimigo

Diferente dos jogadores, inimigos têm estatísticas simplificadas para não travar o jogo:

| Estatística           | O que significa?                                           | Média Sugerida                                             |
| --------------------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| **Defesa (Sucessos)** | Quantos '6' o jogador precisa tirar para acertar o ataque. | **1** (Padrão), **2** (Rápido/Blindado), **3** (Boss).     |
| **PV (Vida)**         | Dano que aguenta antes de cair.                            | **4** (Zumbi), **10** (Humano), **20+** (Monstro).         |
| **Ataque (Dados)**    | Quantos d6 o Mestre rola para atacar.                      | **3d6** (Fraco), **5d6** (Forte), **8d6** (Mortal).        |
| **Dano Base**         | Dano fixo causado se acertar.                              | **2** (Arranhão), **4** (Mordida/Tiro), **6+** (Hit Kill). |

> **Nota de Design:** Infectados não rolam defesa/esquiva. A "Defesa" deles é a dificuldade do jogador acertar o tiro na cabeça ou no ponto vital.
