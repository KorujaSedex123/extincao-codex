# Mecânicas

## ⚙️ O Motor do Jogo

> _"Este sistema foi desenhado para remover a matemática complexa e focar na tensão. O dado é o juiz, mas você é o executor."_

Em **EXTINÇÃO**, não usamos d20, porcentagens ou calculadoras. Tudo o que você precisa é de um punhado de dados de seis lados (**d6**) e coragem.

O sistema divide-se em dois níveis de complexidade:

1. **O Básico:** Tudo o que você precisa saber para criar a ficha e sobreviver à primeira sessão. Como rolar, como passar em testes e o que acontece quando tudo dá errado (Glitch).
2. **O Avançado:** Regras para veteranos. Inclui benefícios para especialistas (Maestria), regras de risco total (Forçar o Limite) e o caos do combate com veículos.
