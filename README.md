# Bem-vindo à EXTINÇÃO

Este não é um RPG sobre ganhar XP e ficar mais forte. É um RPG sobre perder recursos e ficar mais desesperado. **EXTINÇÃO** é um horror tático sobre sobreviventes comuns enfrentando o fim de tudo.

#### Você está preparado para morrer?

Aqui, você não é o protagonista de um filme de ação.

* Você é o **pai de família** protegendo a filha.
* Você é a **enfermeira** com o último frasco de antibiótico.
* Você é o **sobrevivente cansado**, com a mente fraturada e um pente de balas pela metade.

***

#### Regras de Engajamento

O sistema foi desenhado para ser invisível, deixando apenas a tensão na mesa:

* 🎲 **A Regra de Ouro:** Usamos paradas de dados de 6 faces (D6). Você junta os dados do seu Atributo e do seu Treinamento. Se rolar um **6**, você vive. Se rolar uma maioria de números **1**, a catástrofe (_Glitch_) acontece.
* 🧠 **A Mente Quebrada:** O Estresse mata mais rápido que os dentes. Se você surtar e entrar em Colapso, o grupo cai com você.
* 📉 **A Entropia:** Sua armadura vai rasgar. Sua arma vai travar. Seus amigos vão morrer. A única certeza é que nada é eterno.

***

#### O Que Esperar?

* **Dano Letal:** Não existem esponjas de dano. A _Stamina_ é curta e um erro tático custa uma vida.
* **Paranoia Constante:** O vírus não cria apenas monstros; ele cria desconfiança. Um simples arranhão aciona o implacável **Relógio da Infecção**. Quem do grupo está escondendo uma mordida para ganhar mais um dia de vida?
* **Decisões Impossíveis:** Gastar a última bala para salvar um aliado ou guardá-la para si mesmo?

**Bem-vindo ao fim dos tempos. Boa sorte.**
