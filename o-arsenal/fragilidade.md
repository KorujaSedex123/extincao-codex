# Fragilidade

### Armas Improvisadas

_Quando a munição acaba, você usa o que tem à mão. Teste: **Força + Briga**._

| Item                                                                                                 | Dano Base | Características & Riscos                                                                                              |
| ---------------------------------------------------------------------------------------------------- | :-------: | --------------------------------------------------------------------------------------------------------------------- |
| **Garrafa de Vidro**                                                                                 |   **1**   | **Frágil:** Se acertar o ataque, a garrafa quebra (causa o dano) e se torna um _Caco de Vidro_.                       |
| **Caco de Vidro**                                                                                    |   **2**   | **Perigoso:** Se você tiver um _Glitch_, você corta a própria mão (Dano 1 direto no PV).                              |
| **Pedra / Tijolo**                                                                                   |   **1**   | **Arremesso:** Pode ser jogado a curta distância sem penalidade.                                                      |
| **Cadeira / Banqueta**                                                                               |   **2**   | **Escudo:** Se usada defensivamente, concede **+1d6 na Defesa**, mas quebra se o inimigo causar dano.                 |
| **Extintor de Incêndio**                                                                             |   **3**   | **Pesado:** Requer Força 3+ para usar. Se disparado no rosto do inimigo, cega (atordoa) mas gasta a carga.            |
| **Ferramenta (Chave Inglesa/Martelo)**                                                               |   **2**   | **Durável:** Não quebra fácil. Conta como arma normal, mas tem alcance muito curto.                                   |
| **Frigideira**                                                                                       |   **2**   | **Barulhenta:** Se acertar a cabeça, gera um som alto (+1 no Dado de Ruído) mas pode atordoar Infectados (1-2 no d6). |
| Armas improvisadas sempre quebram se você rolar um **Glitch** (Falha Crítica). Não se apegue a elas. |           |                                                                                                                       |
