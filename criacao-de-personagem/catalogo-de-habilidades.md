#### Método: Como Criar Novas Qualidades

Para criar uma qualidade equilibrada, escolha um dos pilares abaixo:

1. Bônus de Dados (+2d6): Para ações muito específicas (ex: "Escalar", "Mentir").
2. Redução de Dificuldade: Para perícias técnicas que exigem precisão (ex: "Hackear", "Medicina").
3. Margem de Sucesso (5 e 6): Para representar força física ou maestria absoluta em um atributo.
4. Recurso Protegido: Garantir que algo não acabe ou não quebre facilmente.

* Custo Sugerido: 2 pts para bônus situacionais; 3-4 pts para bônus frequentes; 5 pts para algo que altera o destino (como evitar a morte ou o Glitch).\*

Concedem pontos extras. Eles humanizam o personagem através de suas falhas e traumas.

| ----------------------- | --------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------- |

#### Método: Como Criar Novos Defeitos

Um bom defeito deve gerar drama na mesa, não apenas números negativos. Escolha uma base:

1. Penalidade de Dados ($$-2d6$$): Para sentidos prejudicados ou traumas (ex: "Fobia de Sangue").
2. Aumento de Dificuldade: Para representar fraquezas mentais ou emocionais.
3. Gatilho de Condição: Algo que acontece quando uma condição é metida (ex: "Se chover, você sente dor nas juntas e perde dados").
4. Custo de Manutenção: O personagem precisa de algo constante para funcionar (remédios, vícios, rituais).

* Ganho Sugerido: 2 pts para algo contornável; 3 pts para algo que atrapalha em combate; 4-5 pts para algo que coloca sua vida (PV) ou a do grupo (Ruído) em risco constante.\*

{% hint style="info" %}
### Dica de Mestre: A Economia de Pontos

* O jogador começa com 0 pontos de Qualidade.
* Para comprar uma Qualidade de 3 pontos, ele deve escolher Defeitos que somem 3 pontos.
* Isso força a criação de personagens imperfeitos e realistas. Em "EXTINÇÃO", ninguém é um super-humano sem ter uma cicatriz ou um vício que o mantenha "humano".
{% endhint %}
